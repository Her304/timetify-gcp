# Events

- Endpoints: `GET/POST /api/events/?week=YYYY-MM-DD`, `GET/PATCH/DELETE /api/events/<pk>/` (creator-only), `PATCH /api/events/invites/<pk>/`, `POST /api/events/<pk>/request-join/`, `POST /api/events/<pk>/rsvp/`.
- **`/rsvp/`**: lightweight accept/decline from a chat event card — finds the caller's invite by event PK, no invite PK needed. Body: `{status: "ACCEPTED"|"DECLINED"}`.
- **`/create` slash command in chat**: typing `/` in the chat input opens `SlashCommandMenu`; selecting "event" opens `ChatEventWizard` (2-step: **step 1** name + date → **step 2** shared free-time picker + start/end + location). Step 2 fetches everyone's shared free slots for the chosen day via `POST /api/availability/shared-gaps/` with a single `date` param (see [availability doc](availability-study-coordination.md)); tapping a slot chip prefills the from/to time inputs, which stay editable (free times are suggestions — an out-of-slot time just triggers the normal 409 overlap flow). On submit, calls `POST /api/events/` with `source_chat_room_id` + all chat member IDs as `invite_user_ids`. Backend auto-posts an `event_card` message to that room. Frontend injects an optimistic card immediately. `EventCardBubble` renders going/can't-go RSVP buttons calling `/rsvp/`. Components: `components/chat/{ChatEventWizard,EventCardBubble}.jsx`. (Standalone "find a time" / `FindTimeSheet` study-invite flow still exists separately.)
- **Repeating events expand** in list response — each occurrence has `occurrence_date` set; frontend places tiles by that.
- **Visibility**: PRIVATE/SEMI → creator + ACCEPTED invitees; PUBLIC → accepted friends of creator. PENDING invitees see bell invite only.
- **Chat room**: created eagerly if `create_chat=True` (default); no lazy fallback. Accept adds member; delete event → room's events SET_NULL but room stays.
- **Join requests**: PUBLIC + `allow_join_requests=True` only. Host accepts/declines via invites endpoint.
- **Conflict resolution**: overlap → `409 {error:"overlap", creator_conflicts, invitee_conflicts}`. Resend with `conflict_resolution` (`skip`|`keep_both`) + `proceed_invitee_conflicts`. Skip records (`CourseSkip`, `EventOccurrenceSkip`) CASCADE-delete with course/event.
- **Schedule skips**: `GET /api/schedule-skips/?week=YYYY-MM-DD` returns `{course_skips, event_skips}`.
- Frontend: `components/events/{AddEventModal,EventBlock,EventDetailsModal,ConflictSheet}.jsx`. `EventBlock` (accepted state) fills light lime `#DCF5A9` with `#3F5E14` accent/border — **not** the saturated `T.lime` token, which reads too bold as a block fill (see [key-gotchas](key-gotchas.md) for the matching course-block convention). `z-index: 10`. Redacted (private, dashed lilac) and pending-invite (dashed coral) states keep their own distinct treatment. `ConflictSheet.jsx` variants: `creator`, `self`, `host`.
