# Static Pages / Content Voice

`frontend/src/components/{about,help,community,terms,privacy}/` — marketing/legal pages routed at `/about`, `/help`, `/community`, `/terms`, `/privacy` in `App.jsx`. Not behind auth.

**Voice is per-page, not global — check the file before editing copy:**
- `about.jsx`, `help.jsx`, `community.jsx` — **formal British English** by explicit request: no "u"/"ur", no contractions, "artificial intelligence" spelled out (not "ai"), British spellings ("centre", "organising"). Still all-lowercase typographically (that's the brand's type system, unrelated to register — kept even in formal copy). Other marketing/product copy sitewide (e.g. `AddMenu.jsx` hints, onboarding tour) still uses the original casual texting-shorthand voice — only these three pages were converted.
- `terms.jsx`, `privacy.jsx` — formal legal documents in **American legal English** (Delaware governing law, American Arbitration Association, DMCA, CCPA/CPRA, FERPA). Left as-is intentionally — these cite real US jurisdiction/statutes; a wording-only Anglicisation pass wasn't wanted, and changing the underlying jurisdiction is a legal decision, not a copy-editing one.

**Help page** (`help.jsx`) is a categorised FAQ/docs page, not just a contact form: hero → jump-nav pills → `FaqSection`/`FaqItem` accordions (six categories: getting started, your schedule, friends and availability, events, chat and snaps, account and privacy) → contact card. `StepShot` component renders a screenshot/recording inline from `frontend/public/help/<name>.png`; if the file is missing it falls back to a "drop `<name>` here" placeholder via `onError` rather than a broken image. Two slots wired up: `syllabus-upload.png` and `event-from-chat.png` (assets not yet supplied).

**Icons on `about.jsx` and `community.jsx`** use Google Material Symbols (Outlined), not `@untitledui/icons` — rendered as `<span className="material-symbols-outlined" style={{ fontSize: 24 }}>icon_name</span>` inside the usual `w-12 h-12` circle, color inherited from the parent's `color` style. Every icon used anywhere in the app must be added to the single consolidated `icon_names=` query param on the Material Symbols `<link>` in `frontend/index.html` (do not add a second `<link>` tag — Google Fonts subsets the font to just the listed glyphs, so a missing name silently renders blank). `Mail01` on the community page's contact button is still an Untitled UI icon, intentionally unchanged.
