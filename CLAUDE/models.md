# Models (non-obvious)

`CustomUser`: `accepted_terms` / `marketing_opt_in` / `onboarding_completed` booleans (set at sign-up; `onboarding_completed` writable via `UserSerializer`). `invite_code` = stable, reusable per-user code backing the personal invite link/QR (`get_or_create_invite_code()` mints lazily via `secrets.token_urlsafe`); `UserSerializer` exposes it **only when serialising self** (never leaks/mints on other users in lists) — see [invite flow](signup-onboarding.md). `pending_email` stages a not-yet-confirmed email during the change-email flow (live `email` unchanged until the emailed link is confirmed — see email-password-reset.md); `username` is user-editable (case-insensitive unique), `email` read-only in `UserSerializer`. `Snap`: `visibility` ∈ `all_friends|selected|group`; natural expiry doesn't set `is_removed`. `Message.message_type` ∈ `text|study_invite|event_card` with `metadata` JSON. `event_card` metadata: `{event_id, name, date, start_time, end_time, location, creator_username}`. `ChatRoomMember.is_admin` gates group ops; auto-promote oldest on last admin leave. `FunctionRestriction.expires_at` null = permanent. `ExternalCalendarEvent`: blocks calendar; never exposes `title` cross-user. `Event`: `visibility` ∈ `PRIVATE|SEMI|PUBLIC`; `chat_room` null until first accept. `Course.rep_date` / `Event.repeat_days` = `"MON,WED"` format.
