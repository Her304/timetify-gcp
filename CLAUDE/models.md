# Models (non-obvious)

`CustomUser`: `accepted_terms` / `marketing_opt_in` / `onboarding_completed` booleans (set at sign-up; `onboarding_completed` writable via `UserSerializer`). `Snap`: `visibility` ∈ `all_friends|selected|group`; natural expiry doesn't set `is_removed`. `Message.message_type` ∈ `text|study_invite|event_card` with `metadata` JSON. `event_card` metadata: `{event_id, name, date, start_time, end_time, location, creator_username}`. `ChatRoomMember.is_admin` gates group ops; auto-promote oldest on last admin leave. `FunctionRestriction.expires_at` null = permanent. `ExternalCalendarEvent`: blocks calendar; never exposes `title` cross-user. `Event`: `visibility` ∈ `PRIVATE|SEMI|PUBLIC`; `chat_room` null until first accept. `Course.rep_date` / `Event.repeat_days` = `"MON,WED"` format.
